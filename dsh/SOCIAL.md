# Launch copy

## GitHub tagline

Persistent, quality-gated, resource-aware execution plans for DeepSeek Harness agents.

## 中文长文案

很多 AI Agent 会“列计划”，但不会真正把计划做完：指标没达标也宣布完成，产物没有验收证据，GPU 状态在阶段切换后早已失效，长任务还会频繁停下来等用户确认。

DSH ProgressTarget 把普通待办列表升级为可执行契约：每个阶段都有截止时间、结构化质量硬目标、可消费交付物、验收证据、资源计划和可审计的重试记录。阶段启动、转换和重规划时会刷新服务器状态；可分片工作必须覆盖所有可用服务器；交付物缺失时，即使超时也不能跳到下一阶段。

一句话：让 Agent 不只会规划，而是被约束着持续执行，直到交付真正可用。

项目地址：https://github.com/02TJS/ProgressTarget

## 短文案

开源了 DSH ProgressTarget：给 DeepSeek Harness Agent 加上持久化计划、质量门、交付物门、截止时间、动态 GPU 发现、多服务器分片和递归重估。Agent 不再“写完计划就算完成”，而是持续执行到交付物真正可用。

https://github.com/02TJS/ProgressTarget
